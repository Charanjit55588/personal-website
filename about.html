About Me

Hi, I'm Charanjit.

I'm a Software Developer in Test / Senior Quality Analyst based in Brampton, Ontario, currently automating mobile, web and API testing at TELUS International. Over 10+ years I've worked across fintech-adjacent, retail, food-service and healthtech products — designing test automation frameworks, wiring up CI/CD pipelines, and making sure bugs get caught long before a user finds them.

My focus areas: BDD-driven mobile & API automation (Java, Appium, Cucumber), cross-platform testing (iOS, Android, Smart TV, Chromecast, set-top boxes), and building the reporting and dashboards that keep product and engineering teams honest about coverage. I've also trained and supervised co-op students and led offshore-onshore collaboration on release cycles.
